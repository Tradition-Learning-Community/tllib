# Descriptor Envelope

Published contract: `TLC-HC-DESCRIPTOR-ENVELOPE@1.0.0`.

```json
{
  "feature_id": "TLC-FC-00-MASTER-001",
  "representation": "record",
  "references": [],
  "unresolved": [],
  "dependencies": [],
  "provenance": {},
  "status": {}
}
```

The carrier preserves these fields and does not interpret references, status, or
opaque values. Domain-specific fields remain deferred to consuming packages.
